# Resilient Live Polling System

## Tech Stack
- React + TypeScript
- Node.js + Express
- Socket.io
- MongoDB

## Features
- Real-time polling using WebSockets
- Server-controlled timer synchronization
- Late joiner handling
- Refresh-safe state recovery
- One vote per student enforced on backend

## How to run locally
1. Start MongoDB
2. Backend:
   - cd backend
   - npm install
   - npm run dev
3. Frontend:
   - cd frontend
   - npm install
   - npm run dev
